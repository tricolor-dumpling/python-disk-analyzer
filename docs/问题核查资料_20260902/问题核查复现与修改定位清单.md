## 三、建议测试脚本/夹具（后续实施）

### A. 对比与趋势

构造同根快照时间点：当前、23 小时前、25 小时前、8 天前；另造跨盘基线。验证：

- 对比页 loading 必须转成功/错误/扫描中状态；
- 较昨日只命中 24 小时内；较上周只命中 `(24h, 7d]`；
- 跨盘选择要有明确提示；
- 无快照/损坏快照不能无限 loading。

### B. 二次扫描和停止

采样状态序列：`idle → running → completed/aborted/error`，分别测试完成后重扫、保存后重扫、第一次中止后重扫、连续点击启动。重点字段：`running`、`scan_version`、`roots_done`、`result_ready`、`save_ready`、`stop_requested`、`stop_reason`。

### C. 视图与动画

数据加载后在 0ms、100ms、500ms、动画结束四个时点截图：矩形图→排行→表格→矩形图；同时记录两个容器 hidden/class、canvas 数量、动画数量。主题按钮和设置选项分别从中心/边缘点击，桌面/窄屏/Edge/reduced-motion 各跑一遍。

### D. 快照安全操作

必须使用临时 `LOCALAPPDATA`/`DSA_SNAPSHOT_DIR` 或 mock 数据目录。删除测试应覆盖：单盘、整会话、已跳过根、路径越界、文件不存在、删除失败、台账恢复、清单原子写。

### E. 导出

覆盖无结果、全量完成、多盘指定 root、空结果、未知大小、CSV BOM/转义、JSON UTF-8、Content-Disposition 和命令面板入口。原错误 JSON 只应在无可导出结果等保护场景出现。

### 真机复现（桩态确定性探针，浏览器渲染层）

探针 `scripts/dev/u50_repro_probe.mjs`（桩态 fetch，零写操作）在隔离数据目录 Flask（`%TEMP%` 重定向）上运行，Playwright chromium 151 headless。关键帧每 100ms，判读交 GPT-5.6 Luna（opentoken `gpt-5.6-luna`，见流程 §经 workflow agent provider/model 通道）。

**2-6 扫描环形动画回跳 —— 已复现（高置信）**
- 客观测量（getComputedStyle transform 角度，100ms 采样 × 3s）：
  `-90→-10°` 匀速（0-600ms）→ t=700ms **-87.5°**（瞬跳 -76°）；此后每 1200ms 重复一次（t=1300→1400、1900→2000、2600→2700 各 -76° 瞬跳）。
- 与手册候选根因 **完全吻合**：`donut-spin` keyframes 只定义 `to{transform:rotate(360deg)}` 而元素带 `rotate(-90)` 属性 → 每 1.2s 实际转 450°、循环结束回跳 90°（-76° = 90° 回跳减采样窗内继续前进的 ~14°）。
- Luna 目视（scan-ring-006/007、026/027 特写）：006→007 弧从 3 点明显移回 4 点方向（支持）；013→014 / 019→020 帧间弧位接近（部分支持）。综合判定已复现。

**2-11 主题扩散铺满 —— 已复现（高置信）**
