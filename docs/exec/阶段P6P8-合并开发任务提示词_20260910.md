## 二、P7：主题扩散修复（问题 10）

### 2.1 任务与根因（实测定位，逐条）

| # | 根因 |
| --- | --- |
| 1 | `theme.js:94` 只校验 `typeof ev.clientX === "number"`；`main.js:45` 绑 `click` → **键盘 Enter/Space 或 `el.click()` 产生 `clientX=clientY=0`** 被当合法坐标 → 圆从**视口左上角**扩散 |
| 2 | `main.js:245` 命令面板「切换主题」传 `null` → 走直切分支，**完全没有扩散** |
| 3 | `theme.js:104-106` 用视口空间（`clientX/clientY` + `window.innerWidth/innerHeight`），但 clip 作用于 `::view-transition-new(root)`（`theme.js:121-122`），**代码中无任何空间换算**（无 `getBoundingClientRect` / `scrollY`） |
| 4 | `theme.js:122` 的 WAAPI options **没有 `fill`** → 450ms 结束时 `clip-path` 计算值回到 `none`，未被圆覆盖的像素在一帧内全部变新主题 = `theme.js:84` 自述的"一次性铺满帧"。几何上顶部起点使底边约 34% 时间被穿过、最远水平角约 92% 才覆盖 → 半径不足**只在底部两角显现**（与用户"底部触底后两端瞬间完成"吻合） |
| 5 | `settings.js:197` 的 300ms TTL + `settings.js:226-233` `pointFrom` 回退：慢点击/点在外边距/键盘激活时圆心退回**控件中心** |

**探针盲区（必须一并修，否则"验收通过"是假的）**：`u62:115` 断言的 `documentElement.style.clipPath` **从未被写入**（`theme.js:114/127` 清的是它）→ 断言恒真；`u62:253` 是死分支；`u63:90-112` 只比对 keyframe 字符串，**测不到渲染圆心**。

### 2.2 设计决策（D7-1…D7-5）

- **D7-1 坐标空间对齐**：用 clip 参考盒换算
  `const b = documentElement.getBoundingClientRect(); x = ev.clientX - b.left; y = ev.clientY - b.top; W = b.width || documentElement.clientWidth; H = b.height || documentElement.clientHeight; maxR = Math.hypot(Math.max(x, W-x), Math.max(y, H-y)) * 1.02 + 16;`
- **D7-2 消除一帧铺满**：WAAPI options 加 `fill: "forwards"`；伪元素随转场销毁，不残留。
- **D7-3 伪坐标兜底**：`ev.detail === 0 && ev.clientX === 0 && ev.clientY === 0` 视为"无坐标" → 用触发元素 `getBoundingClientRect()` 中心，或直切；`main.js` 命令面板项传入**面板项元素中心**以恢复扩散。
- **D7-4 设置弹窗坐标**：去掉 300ms 时间 TTL，改为"下一次 `change` 消费 / 弹窗关闭时清空"；`pointerdown` 记录放宽到整个 `#setting-theme` 组。
- **D7-5 验收必须像素级**：圆心拟合 ≤4px、末帧前旧主题像素为 0、相邻帧新主题面积跳变 ≤30% 视口面积。

### 2.3 实现步骤

1. 新增 `scripts/dev/p07_theme_pixel_probe.mjs`：CDP screencast（10–20ms/帧）覆盖 ①顶栏 9 点；②设置弹窗选项中心与 +12px；③键盘激活；④命令面板；⑤滚动变体（`scrollY=0/300/600`，若页面可滚）。每组输出帧序列 + 圆心拟合 + 面积曲线。
2. 按 D7-1…D7-4 改 `theme.js`、`main.js`、`settings.js`（`style.css` 如需）。
3. **修探针盲区**：`u62` 死分支与恒真断言改为真正可验"终态无 clip 残留"；`u63` 增**像素层**圆心断言（不再只比 keyframe 字符串）。
4. 保留 reduced-motion / 不支持 VT / 连点防护三条既有红线逻辑。

### 2.4 约束

- **不得**删除 reduced-motion 直切分支（`theme.js:93-98`）；
- **不得**破坏 `u62` 的 20 组连点计划与 rapid 终态语义（终态 ∈ {target, startTheme}，等待 800ms）；
- **禁止**用"把扩散动画改成直切"绕过问题；

### 2.5 DoD（P7）

1. 顶栏、设置弹窗、命令面板、键盘激活四条路径圆心均等于**真实触发位置**（容差 ≤4px）；
