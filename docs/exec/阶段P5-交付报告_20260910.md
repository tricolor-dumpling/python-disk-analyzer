### 2.2 关键实现要点

1. **盘符唯一来源** `components/drives.js`：`loadDrives()` 带 in-flight 去重（同一 tick 多次调用只打一次接口）；失败返回空数组 + `drivesFailed()`，**绝不硬编码兜底**；`saveSelectedRoots()` 写 `last_roots` 失败不抛（选盘不阻塞首开）。
2. **默认根** `workspace.applyDefaultRoot(startup)`：`上次浏览(pds_last_browse_v1) → 枚举盘首个 ready 盘 → ""`；`""` 时 `#browse-root` 留空、`topbar` 不发起启动浏览（零 400 请求、零 console 噪声）。
3. **连带修正**：`workspace.browsePath` 在 `currentRoot` 未落定而用户已显式输入路径时用 `target` 补会话根——否则 `POST /api/browse` 因 root 空而 400（现象：「路径明明填了却报缺少 root 参数」）。
4. **`/api/roots` 就绪判定** `os.path.exists(root)`：Windows 对无介质驱动器返回错误而非阻塞，接口保持秒回；不可用盘符 `ready=false` + label 追加「未就绪」，**保留在列表里**（不静默丢弃用户的盘）。
