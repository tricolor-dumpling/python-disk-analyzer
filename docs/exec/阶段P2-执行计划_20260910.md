## 一、任务与根因（计划第八章）

**现象**：`#treemap-wrap` 在**非矩形图→非矩形图**的切换中也被取消隐藏，整幅矩形图重现并淡出 120ms（≈7–12 帧），用户看到"闪过"。

**根因**：
- **R1（主因）** `workspace.js` 的 `crossfadeView(seq, showTreemap)` 把方向判成"矩形图 vs 表格"二元，而非"上一视图 vs 下一视图"：目标非矩形图时矩形图被当作退场元素 → `removeAttribute("hidden")` + `style.opacity="1"` → 整幅重现 120ms。
- **R2（形态）** `style.css` 两个容器同为 `position:absolute;inset:0` 且无 `z-index`，`#treemap-wrap` 在 DOM 中靠后 → 叠加时矩形图在上层。
- **R3（半成品）** `workspace.js` 加了 `.v-crossfade` 类，但 `style.css` 中**不存在该规则**（层序/指针/裁剪从未定义）。
- **R4（卫生）** 终态隐藏推迟到两个 WAAPI 动画 `finished` 之后（连点会反复重启）；`treemap.pause()` 只 `cancelAnim()`，不 disconnect ResizeObserver、不重绘终帧、不清画布 → 中途切走会闪出残缺位图。
- **R5（教训）** 上一批 8 轮"未复现"是因为探针只断言 700–800ms 后的终态 + `u66` 结尾是幂等点击 → **断言口径盲区**。

## 三、设计决策（计划 D2-1…D2-4，直接执行）

- **D2-1** 保留"矩形图参与时"的 120ms 交叉淡化，但方向判定改为**上一视图 vs 下一视图**：`treemapInvolved = prev === "treemap" || mode === "treemap"`，仅 `treemapInvolved && prev !== mode` 才 `crossfadeView`，否则直接 `finishViewSwap`。
- **D2-2** 补齐 `.v-crossfade` CSS 语义（入向视图在上层 + `pointer-events` 正确），并核对与 `#browse-loading`（`z-index:5`）、全屏态的层序。
- **D2-3** `treemap.pause()` 真暂停：断重绘、收束终帧、暂停期间 `doResize()/highlightKey()` 直接返回、隐藏态不响应 hover 重绘。
- **D2-4** **关闭依据只能是帧级断言**（写入 README 与复现清单）。
- **禁止**用"120ms → 0ms"或"关闭全部转场"消灭残留。
