## 四、硬性要求（红线与纪律，违反即返工）

### 【第 0 条 · 最高目标（总纲，凌驾以下一切条款）】
以一遍过、不返工、高质量产出为最高目标；不需要考虑 token 和时间成本消耗；遇到不确定的问题随时向用户提问；需要任何权限，可提出（合理范围用户可允许）；开发结束请更新相关文档；开发结束后停掉后台任务；能够有更好的方式得到最终效果，就选择更好的方式，不需要考虑时间和金钱成本。

### 手册伍章红线（1–11 条全量执行）
- 严禁夹带：每个落地项一个独立变更集；禁止把 UI 美化混入功能修复；实现前先看「先复现/先核对」对应证据。

### 【Git 版本管理纪律（与阶段 C/D/E/F 相同，强制执行）】
