## 四、硬性要求（红线与纪律，违反即返工）

### 【第 0 条 · 最高目标（总纲，凌驾以下一切条款）】

以**一遍过、不返工、高质量产出**为最高目标；不需要考虑 token 与时间成本；遇到不确定的问题**随时向用户提问**；需要权限可提出（合理范围用户会允许）；开发结束**必须更新相关文档**、**必须停掉后台任务**；如果有更好的方式能得到最终效果，就选更好的方式，不要考虑时间与金钱成本。

**结束进程前必须先确认：该进程是不是自己启动的、结束它会不会影响别的内容。** 尤其注意：**不得触碰 Everything 进程与用户自带 Edge 实例**——服务/探针清理只限自己启动的进程。

### 【零号红线 · 本阶段不得改动生产代码】

P0 的产出是**工具与证据**，不是功能。任何生产代码改动都属越权，一经发现必须立即 revert 并在交付报告登记。若执行中发现"必须改生产代码才能验证"，**停下并呈报用户**，不要自行放行。

### 【视觉验收强制条款（必须创建 gpt-5.6-luna 子代理）】

1. P0 产出的**所有截图/帧序列**（基线对照截图、帧记录器输出、主题 screencast 帧）必须由 **gpt-5.6-luna 子代理判读**。DSH 唯一可指定模型的通道是 workflow 工具：`agent(prompt, { provider:"opentoken", model:"gpt-5.6-luna" })`；普通 `subagent` 强制继承默认模型（无图像能力），不可用于判读。
2. 判读 prompt 必须给**绝对路径**（Luna 工作目录与主代理不同，相对路径会误报"文件不存在"）。
3. Luna 结论必须与**量化采样**互证；冲突时以量化采样为准，并在交付报告记录差异原因。
4. 禁止主代理或默认模型对任何截图/帧序列下 PASS/FAIL 结论。

### 【动画类问题强制条款 · 短间隔截图】

1. **禁止用终态断言验收动画。** 上一批 `2-2 视图残留` 8 轮"未复现"的根因就是探针只在 700–800ms 后采样终态，而缺陷窗口只有 120ms。
2. 采样节奏硬性要求（本机已实测可用）：

| 方式 | 实测节奏 | 用途 |
|---|---|---|
| 页内 `requestAnimationFrame` 记录器 | ≈16.7ms/帧 | DOM 状态（`hidden`/`opacity`/`elementFromPoint`） |
| CDP `Page.startScreencast` | 10–20ms/帧 | 像素（圆心、面积曲线） |
| Playwright `page.screenshot()` | **≈130ms/张** | **仅限静态终态**，禁止用于 120ms 级动画 |

3. P0 的帧记录器必须**从触发前开始采样、覆盖动画全程 + 200ms 收尾**，且必须能复现出 `P2-视图切换帧级证据.json` 同等的证据（即能抓到"违规帧"）。
4. **如果 P0 的帧记录器抓不到问题 2 的违规帧，视为工具链不合格，不得进入 P1。**

### 【探针与夹具纪律】

- 探针**必须**在 `finally` 中 `browser.close()`，避免残留 chromium 进程。
- 探针**不得**写入用户真实数据目录（`%LOCALAPPDATA%\PythonDiskScanner`）；写操作一律走夹具根或页内 `fetch` 桩。
- 夹具生成**不得**覆盖或删除既有五类夹具（`current`/`23h`/`25h`/`8d`/`cross-drive`）。
- 探针默认 `headless: true`；参数统一 `--base` / `--out` / `--viewports`。

### 【Git 纪律】

- 分支 `stage-p0`；一任务一变更集；提交前 `git status` 干净或仅剩预期文件。
- 阶段结束：`git status --short` → `git add -A` → 提交 → `git tag -a p0-visual-harness` → 记录 tag 与 commit 范围到交付报告。
- **禁止**提交 `__pycache__`、`.venv/`、`dsh-image-gen/`、`%TEMP%` 产物、本机绝对路径配置。
- **禁止** `git push --force`、禁止改写已推送历史。

### 【进程与资源清理纪律】

阶段结束必须执行并在交付报告贴出**清理前后**的进程/端口清单：

```powershell
Get-NetTCPConnection -LocalPort 5000 -State Listen -ErrorAction SilentlyContinue | Select-Object LocalPort,OwningProcess
Get-Process python,node,chrome,chromium,Everything -ErrorAction SilentlyContinue | Select-Object Id,ProcessName,StartTime
# 只停自己启动的 PID；确认端口释放；清理 %TEMP% 下自己的探针产物
```

红线：不得按镜像名批量杀（`taskkill /F /IM python.exe` 之类）；不得动 Everything 与用户 Edge。
