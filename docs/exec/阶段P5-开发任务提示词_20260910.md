## 一、任务与根因（问题 7；已在 P4 交付后的代码上核对行号）

### 1.1 术语裸奔 + 语义自相矛盾（问题 7 的直接成因）

- 「基线 / 目标」在 UI 中多处出现且**只用原生 `title=` 解释**：
  - `compare.js:862-898`（`COMPARE_PAGE_HTML`）：`#compare-baseline`（`:870-872`）、
    `#compare-target`（`:876-878`，**只读**）、页头副行 `#compare-root-line`（`syncForm` `:212-221`）；
  - `snapshots.js:621-633 prefillAndGoCompare` 与趋势卡副行/tooltip；
  - `main.js` 命令面板 hint、`workspace.js` 旧称「历史对比」。
- **语义自相矛盾（代码自述，P4 后仍在 `compare.js:11-15`）**：`/api/compare` 的「当前」侧 =
  `fullscan.result(root)` 或 SDK 直扫，**并非快照文件**；「目标=同盘符最新快照」只是标识性文案。
  → 用户看不懂的根因：**把一个"当前磁盘状态"伪装成"目标快照"**。

### 1.2 首开无选盘 + 盘符硬编码

- 冷启动：`main.js:370 bindOnboarding()` → `components/onboarding.js:15-46`（`showGuide`/`dismissGuide`/
  `loadGuide`/`bindOnboarding`），引导弹层 DOM 在 `web/templates/index.html`；**全程没有选盘步骤**。
- 唯一输入框是工作台工具栏 `#browse-root`（`workspace.js:1154`，HTML 里写死 `value="D:\"`），
  盘列表是**硬编码 datalist**：`workspace.js:1155` 的 `#roots-suggest` 固定 `C:\ D:\ E:\ F:\`。
- 后端**已有**真枚举：`fullscan.py:309 _enumerate_roots()`（`GetLogicalDrives()` + A–Z 回退），
  但结果**从未传到前端**（`app.py` 无对应响应字段/路由）。

### 1.4 P4 交付后**必须一并考虑**的新事实（否则会踩回归）

1. 对比页页头现在有 5 个控件：`#compare-baseline`、`#compare-target`、`#compare-depth`、
   `#compare-hide-zero`、`#btn-compare`（`compare.js:862-898`），页体有 `#compare-crumb`
   （`:903`，未下钻 `hidden`）。**1366×768 零页面滚动**是 u34 ⑩a 的硬断言 → 改页头布局必须复跑。
2. 结果缓存键含 `depth` + 开关口径（`resultCacheMatch`，`compare.js:226-241`）；跨页共享缓存
   （snapshots.js 写入，无这两个键）沿用「不重发」语义（u34 ⑧b / smoke A17·A18 红线）。
   **改术语时不要动缓存判定逻辑。**
3. `/api/compare` 支持 `depth` / `drop_zero` / `order_by`，`report` 键集合被
   `tests/test_api_contract.py` **精确冻结（15 键）**——P5 若加字段，同提交更新断言。
4. 下钻 = 请求 root 换成子目录；`app.py _cached_current_rows()` 会从**祖先根缓存**派生子树
   （同步快路径）。P5 改默认根/首扫范围时，注意与下钻 root 的交互（下钻根必须落在已扫根之下）。
5. `state.js` 的 `compare` 形状已含 `depth` / `hideZero` / `drillRoot`（P4 清理后）；本阶段若要新增
   `browse`/`onboarding` 相关键，**同一提交**更新 `state.js` 注释与 §3.2 形状。

## 三、设计决策（计划 D5-1…D5-5，直接执行；括号内为 P4 后的落地补充）

- **D5-1 改词**：「基线」→「对比基准（历史快照）」；「目标」→「当前磁盘状态」。
  **删除只读的「目标」输入框**，改为摘要区一行「当前：D:\ · 数据时间 …」。
  （落地补充：`#compare-target` 被 smoke `:1091,:1114,:1135` 与 u34 ①b/①d/⑦b 断言 → 删除时**同提交**改为
  断言新的「当前状态行」元素 id（建议 `#compare-current`），并保留 `data-*` 便于探针读取。）
- **D5-2 基线选择器升级**：datalist 文本框 → 下拉列表，每项「时间 · 盘符 · 自动/手动」，默认项标注「最近一份」。
  （落地补充：`#compare-baseline` 与 `#baseline-suggest` 被 smoke `:1092,:1117` 断言 → 若换成 `<select>`，
  保留 `#compare-baseline` 这个 id 挂在 select 上，并同提交更新 `list` 属性断言为「下拉可选项数」。）
- **D5-3 首开选盘**：引导弹层增加「选择要分析的盘」步骤，数据源 = **后端真枚举**（新增 additive 接口），
  选盘结果经 `/api/settings` 写入 `last_roots` 并驱动首次扫描范围。（落地补充：盘符项要能表达
  「不可用/未就绪」，且**可跳过**——跳过则维持既有默认逻辑。）
- **D5-4 默认根去魔法值**：统一「上次浏览 → 枚举盘首项 → 显示"请选择盘符"」，删除 §1.3 表中
  全部 `"D:\\"` 硬编码兜底；盘符列表一律来自新接口，**禁止**再新增硬编码数组。
- **D5-5 术语一致性**：全仓库统一（命令面板 hint、趋势卡 tooltip、README、旧称「历史对比」）；
  对比页**副行**必须自解释（不依赖 `title=` 悬停）。
