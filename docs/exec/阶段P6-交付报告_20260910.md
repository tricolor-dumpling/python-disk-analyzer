### 2.1 关键实现要点

1. **`/api/series` 与前缀聚合**：`_series_value()` 三个口径——`path` 为空 → 快照根聚合总量（`_snapshot_root_stats`，**与 `/api/snapshots` 的 `total_by_root` 同一入口与同一份缓存**）；`path` 非空、`depth` 为空 → 该目录**行自身值**（扫描树父行已含后代，不重复累加；行缺失 → `present=false, bytes=0`，不编造）；`depth ≥ 1` → `compare._rollup` 折叠后合计。缓存键 = `(快照路径, path, depth)`，值随文件签名 `(mtime_ns, size)` 失效；快照被重写/滚动覆盖即自动失效。
2. **`/api/snapshots` 只快不慢**：`_snapshot_root_total()` 下沉到 `_snapshot_root_stats()`（返回 total + rows + 头部元数据），签名与返回语义**逐字不变**；实测 5 份 × 13 万行夹具下冷 853ms → 热 0.9ms，且与 `/api/series` 互 warming（§3.4 ⑤）。
3. **折线几何单一来源**：`viz/line.js` 只做「测量 → 调 `lineGeometry` → 生成 SVG/DOM」，路径与点位全部由 `motion-core.sparklinePath` 派生（`<g transform="translate(pad)">` 平移绘图区）；折线本身**不做入场动画**（探针确定性），悬浮读数只用 `transform/opacity`（不触发布局）。
4. **多选不破坏单选契约**：`rebuildBaselineOptions()` 重建前记录当前选中集并在重建后逐项恢复（否则每次刷新会把多选收敛成单选）；`syncForm()` 只在「目标值未被选中」时才写 `select.value`（HTML 规范下 `value` 赋值会清空其余选中项）。默认路径与修复前一致：挂载/预填后 `selectedOptions.length === 1` 且首项 `data-latest="1"`。
5. **多选触发的趋势口径**：序列请求带 `root`（对比根）+ `path`（下钻目录，未下钻为空）+ `depth`（深度选择器同值）+ `snapshots[]`；缓存键含四者，切页往返不重发。趋势空态三态：`idle`（<2 份）/`loading`/`empty`（数据不足/失败），文案一律给原因。
