## 二、已确认的产品原则

| 原则 | 结论 |
|---|---|
| 产品定位 | 本地磁盘空间分析工作台，而不是普通文件管理器 |
| 核心任务 | 找出占用空间最大的盘符、目录和文件，并快速进入浏览 |
| 默认视觉 | 浅色、专业、低饱和、低噪声、高信息密度 |
| 默认主色 | 品牌蓝 `#3B82F6`；增长关注橙 `#F97316`；减少绿色 `#16A34A` |
| 图表实现 | 优先使用原生 HTML/CSS/SVG，不引入外部 CDN 或大型图表框架 |
| 数据口径 | 只展示 Everything 已索引内容；没有真实容量数据时不伪装成“磁盘已用百分比” |
| 浏览体验 | 全量扫描完成后优先内存索引，禁止因浏览重新查询 Everything |
| API 兼容 | 保持现有 Flask API、前端字段和快照格式兼容 |
| 离线能力 | 打包后不依赖网络；第三方图标或资源必须本地化并保留许可证说明 |
| UI 文案 | 主界面只显示状态、数据和下一步操作；教程、原理说明和详细帮助默认隐藏到帮助弹窗或 tooltip |
| 动效与质感 | 使用克制的微动效与局部玻璃质感增强层次；不影响信息读取、性能和无障碍体验 |
| 玻璃效果 | 仅用于顶栏、状态浮层、概览卡等有限区域；必须提供纯色背景降级，不依赖透明叠加才能辨识内容 |
| 美化策略 | 不局限于玻璃：可按需使用渐变、柔和光晕、层次阴影、细边框、微纹理、图表动效、状态过渡和空态插画，但所有效果必须服务于层级和可读性 |

## 三、全局开发约束

### 允许修改

- `fullscan.py`
- 可新增 `browseindex.py`、前端辅助文件或本地资源
- `app.py`
- `web/templates/*`
- `web/static/*`
- `tests/*`
- `docs/开发方案.md`

### 禁止修改

- 受控修改护栏（定稿 §八.2，P12 起生效；针对 `scan.py`/`compare.py`/`snapshots.py`）：
  1. **回归先行**：任何行为变更必须先有护栏回归（golden/契约测试）合入再动手，
     改实现时同一提交内同步改期望；
  2. **两条红线不变**：快照格式 format v1 与已有 API 字段语义不变，
     新增字段一律 additive（只增不改不删）；
  3. **零破坏传出通道**：`(sizes, contents)` 二元组解包契约与
     `save_snapshot -> Path|None` 返回契约冻结；
  4. **变更面收敛＋独立提交**：单工作项改动面不得超出执行手册触碰文件清单，
     一工作项一提交，保证可单独 revert。
- Everything SDK 接口和快照文件格式
- 已有 API 的字段语义，除非先补充兼容测试
- 运行时从 CDN 加载 CSS、JS、字体或图标

### 每阶段必须完成

1. 先写清设计目标、数据口径和失败态；
2. 实现最小可用版本；
3. 增补单元测试、页面冒烟或集成测试；
4. 执行 `python -m unittest discover -s tests`；
5. 有真机条件时执行对应流程；
6. 更新本文勾选项和进度日志；
7. 记录未完成项，不伪造验收结果。

### 图表范围

#### 1. 顶级目录横向柱状图

- 默认显示 Top 5 或 Top 10；
- 其余项目合并为“其他”；
- 横轴表示相对占比或大小；
- 目录名称支持长文本截断和完整 tooltip；

优先使用简单的 SVG 环形图或 CSS 分段条：

- 当前目录直接子目录占比；
- 当前目录直接文件占比；
- 中间或旁侧显示总大小；
- 空目录显示空态，不渲染误导性的 0% 图形。

- 默认显示排行视图；

### UI 文案克制原则

主界面优先展示数据、状态和下一步操作。删除或折叠“教客户怎么用”的长段落、重复原理说明和操作教学；需要帮助时通过帮助弹窗、tooltip 或错误态中的简短指引提供。

### UI 美化与动效规范

后续 UI 优化不局限于玻璃质感，遵循“适度丰富、层次清晰、内容优先”的原则。可根据页面区域选择以下手段：

#### 可采用的视觉手段

- **色彩层次**：浅色背景分层、低对比度渐变、品牌色光晕、语义色状态背景；
- **玻璃质感**：顶栏、状态浮层、概览卡使用半透明背景、`backdrop-filter: blur()`、细边框和柔和阴影；
- **层次与空间**：卡片阴影、悬浮层、分组边界、细分隔线、局部高亮和渐进式视觉权重；
- **数据表现**：柱状图增长动画、进度条条纹、环形图绘制、数字平滑更新、图表 hover 高亮；
- **交互反馈**：按钮 hover/active、chip 选中、表格行高亮、面包屑切换、成功/错误状态过渡；
- **内容状态**：空态图形、扫描中脉冲、完成状态勾选、错误状态图标、轻量 toast 进入/退出；
- **背景细节**：极低对比度网格、径向光晕或微纹理，仅用于增强层次，不得干扰文字和图表。

#### 使用边界

- 页面进入、卡片出现、状态切换使用 150–300ms 的淡入或轻微位移动画；
- 图表首次出现可以使用 300–600ms 的绘制动画，但不得阻塞数据读取和点击；
- 按钮、盘符 chips、表格行只使用轻微 hover、active 和 focus 反馈，不使用大幅缩放；
- 扫描进度可以使用低对比度条纹或呼吸效果，但必须同时展示明确百分比和文字状态；
- 玻璃效果只用于有限区域，必须有纯色背景、边框和阴影降级方案；
- 渐变、光晕和纹理的对比度必须低于主要数据内容，禁止抢占视觉焦点；
- 图表颜色必须同时配合文字、图例、图标或纹理，不能只依赖颜色表达信息；
- 所有动效必须尊重 `prefers-reduced-motion: reduce`，关闭非必要动画；
- 禁止强反光、霓虹、复杂 3D、持续跳动、无限滚动装饰和影响性能的粒子效果；
- 美化效果不得造成扫描、浏览、筛选、保存和对比操作延迟。

### UI 区域美化建议

| 区域 | 推荐效果 | 控制要求 |
|---|---|---|
| 顶部应用栏 | 半透明玻璃、轻微模糊、滚动时阴影 | 保持导航和状态清晰，模糊不可用时自动降级 |
| 页面标题区 | 柔和径向光晕、渐变强调线、轻微入场 | 不使用大面积高饱和背景 |
| 盘符概览卡 | 细边框、状态色光晕、进度环或分段条 | 不把索引相对占比伪装成真实磁盘使用率 |
| 图表区 | 柱状图绘制、hover 高亮、数值淡入 | 动画短且可跳过，提供文本摘要 |
| 目录列表 | 行 hover、选中态、占比条过渡、交错淡入 | 大数据量时避免逐行复杂动画 |
| 扫描状态 | 进度条条纹、状态点脉冲、完成勾选 | 必须同时有百分比和文字 |
| 空态与错误态 | 轻量 SVG、柔和背景、操作按钮强调 | 不用大段教程替代操作 |
| 弹窗与 Toast | 背景遮罩淡入、面板轻微上移、Toast 滑入 | Esc 可关闭，支持 reduced-motion |

### 视觉优先级

1. 当前扫描状态和索引是否可用；
2. 哪个盘或目录占用最多；
3. 当前目录路径和总大小；
4. 哪些内容相比基线发生变化；
5. 保存、撤销、设置等管理操作。

### 不建议

- 大面积高饱和蓝色；
- 复杂 3D 饼图；
- 卡片嵌套卡片；
- 过多动画和渐变；
- 依赖网络加载图表或图标；
- 把索引内容误写成真实磁盘容量使用率。
