## 〇、防返工承诺与决策记录

所有容易引发二次争议的点，在此一次性裁决。开发阶段若遇本文未覆盖的细节，按「决策记录」的精神类推，不得另起炉灶。

| # | 决策点 | 结论 | 否决的替代方案与理由 |
|---|--------|------|---------------------|
| D1 | 技术栈 | **保持 Flask 静态服务 + 原生 ES Modules，无打包器**。`app.js` 拆为 `web/static/js/app/` 目录模块 | 引入 Vue/React+Vite：改变部署形态，Flask 模板与打包产物双源，长期维护分叉 |
| D2 | Treemap 实现 | **Canvas 2D 自绘 squarified 算法**（约 80 行），DPR 适配，命中检测用矩形边界数组 | D3：体积与学习成本；SVG：千级矩形节点 DOM 开销大、动画掉帧 |
| D3 | Treemap 配色 | **按目录名哈希从 10 色 fixed 调色板取色**（跨导航颜色稳定，同一目录永远同色），占比只做亮度微调；「其他」合并块用中性灰蓝 | 按大小取色：每次下钻颜色全变，无法建立空间记忆 |
| D4 | 主题体系 | `html[data-theme="dark|light"]` + `tokens.css` 全量变量双份；首访跟随 `prefers-color-scheme`，手动切换写 localStorage | 只做暗色：与现有亮色用户习惯断裂；CSS-in-JS：无构建链不适用 |
| D5 | 动效架构 | **所有动效集中在 `motion.js`**（ripple/countUp/FLIP/stagger/sparkline 工具函数）+ CSS 仅承载 loop 类 keyframes；时长与缓动全部引用 motion token，禁止散落魔法数 | 各组件内联手写动画：数值漂移、无法全局降级 |
| D6 | 命令面板（Ctrl K） | 纯前端：数据源=盘符+最近访问+浏览历史+快照+静态命令+**页面跳转**，本地模糊过滤 | 新增后端搜索 API：浏览数据本来就在前端，多余一跳 |
| D7 | 「较昨日/较上周」趋势卡 | **前端从快照列表按时间就近选基线，复用现有 `/api/compare`**，无新后端 | 新增时间序列 API：快照已是全量数据，重复建设 |
| D8 | 扫描状态展示 | 耗时=前端计时；当前盘符/已完成盘符 chips 直读现有 status；**文件计数仅当接口未来提供字段时自动显示**（UI 预留槽位） | 为显示文件数改后端轮询结构：收益低、耦合高 |
| D9 | 表格多选导出 | 前端生成 CSV Blob 下载（复用现有转义与 humanBytes），不动 `/api/export` | 后端新增批量导出参数：接口语义复杂化 |
| D10 | 扫描控制 | 只做**「停止扫描」不做「暂停」**。新增唯一后端接口 `POST /api/fullscan/stop`（置取消标志，fullscan 协程在盘符间检查）；后端未上线前按钮隐藏 | 暂停/恢复：Windows 遍历协程挂起语义复杂且无真实需求 |
| D11 | 视图语义 | Treemap 工具栏「−/+」= **调整「其他」合并阈值**（Top 12/24/48/全部），不是视觉缩放；单击矩形=下钻，双击=回到本级根 | 缩放语义：与下钻冲突，用户心智负担大 |
| D12 | 现有构成图 | 原 `browse-chart` 构成图**由 Treemap 取代**，不再保留两套图表 | 两者并存：信息重复、维护双份渲染逻辑 |
| D13 | **页面模型** | **单屏应用（App Shell）**：主页面 body 零滚动（`overflow:hidden`），视图区弹性填充剩余高度；重内容功能走 hash 子页面（`#/compare`、`#/snapshots`），SPA 内切换不刷新、不重载资源 | 长滚动单页：即当前线上形态，核心信息被稀释、页面长达数屏；弹窗承载重内容：对比表格+图表在弹窗内局促且无法深链 |
| D14 | 零滚动边界 | **页面级滚动=0；面板内滚动允许**（列表、快照列表、对比表格、低屏时的右栏）——这是标准应用范式；<900px 宽（窄分屏/移动）退化为传统纵向滚动，属声明过的例外 | 强制一切内滚：移动端体验灾难；一切靠弹窗：违反 D13 |
| D15 | 存储 chips 语义 | 存储概览卡的盘符 chips **只切换环形图数据，不切换浏览目录**；跳转浏览用卡内「浏览此盘」按钮 | chips 同时切目录：用户浏览到一半被劫持 |

**本方案唯一的新增后端工作：D10 的 stop 接口。其余（含子页面路由）全部为前端改造，API 契约零变更。**

### 4.3 其余规范

- **字体**：沿用 Segoe UI/Microsoft YaHei 栈；**所有数字处 `font-variant-numeric: tabular-nums`**（大小、占比、计时器），避免动画中数字抖动。
- **圆角**：卡片 16px / 控件 10px / chips·徽章 999px。
- **毛玻璃**：顶栏与浮层用 `--card-glass` + `backdrop-filter: blur(12px)`。
- **发光**：仅暗色主题且仅用于三类元素——主按钮 hover/扫描中、进度环、treemap 新生长块；亮色 `--glow-*` 为空即自动关闭。
- **图标**：内联 SVG sprite（现有 ICONS 表扩充），线宽 1.8，禁止混用面性图标。
- **灰阶使用边界（评审裁决）**：`--faint` 仅用于禁用态与输入占位符；一切正文辅助文字最低用 `--muted`（暗色卡底上 `--faint` 仅约 3.5:1，不达 AA）。
- **色盲冗余（评审裁决）**：`--up/--down` 不得仅靠颜色编码——增长/缩减必须叠加符号（▲/▼ 前缀）与方向（发散条向左/向右）双编码；sparkline 终点同配 ▲/▼。
- **Tooltip 规格**：底 `--card-glass`+blur(12px)、圆角 10px、阴影 `--shadow-lg`、跟随鼠标偏移 (12,12)、视口边界自动翻转、显示延迟 150ms。
- **Motion tokens**（写入 tokens.css）：`--dur-1:120ms --dur-2:200ms --dur-3:320ms --dur-4:600ms`；`--ease-out:cubic-bezier(.16,1,.3,1) --ease-spring:cubic-bezier(.34,1.56,.64,1) --ease-inout:cubic-bezier(.65,0,.35,1)`。

### 性能红线（验收逐条测）

1. 动画只允许 transform/opacity（canvas 内除外）；禁止触发 layout 的属性参与动画。
2. Canvas 双层：静态层（矩形+文字）与特效层（扫掠/粒子/光晕）分离，特效层按需重绘。
3. `devicePixelRatio` 适配；resize 用 rAF 节流。
4. 列表 >200 行启用虚拟滚动（现有紧凑列表逻辑扩展）。
5. `will-change` 仅动画期间挂载，结束移除。
6. 1000 矩形下 hover/下钻交互 ≥50fps（验收基准机）。
7. **App Shell 挂载后 body `scrollHeight === clientHeight` 恒成立**（桌面断点内，任何数据量/任何视图）。

### prefers-reduced-motion 降级总表

| 动效类别 | 降级为 |
|---------|--------|
| 所有循环类（极光/流光/呼吸/扫掠/脉冲/shimmer） | 静止（保留静态样式） |
| 入场类（stagger/生长/sweep/count-up） | opacity 120ms 或直接终值 |
| 转场类（下钻 FLIP/主题扩散/全屏/页面切换 L0-5） | 直接切换（≤80ms opacity） |
| 粒子庆祝 L2-4 | 不播放 |
| 功能性反馈（toast 滑入、错误 shake） | 保留但 ≤120ms（属状态提示，非装饰） |

async function transitionTo(page) {

}

```js
// motion.js — 主题圆形扩散（L0-1）
function switchTheme(next, ev) {
  const x = ev?.clientX ?? innerWidth - 48, y = ev?.clientY ?? 40;
  if (!document.startViewTransition) { document.documentElement.dataset.theme = next; return; }
  const t = document.startViewTransition(() => { document.documentElement.dataset.theme = next; });
  t.ready.then(() => {
    document.documentElement.animate(
      { clipPath: ['circle(0 at ' + x + 'px ' + y + 'px)', 'circle(' + Math.hypot(innerWidth, innerHeight) + 'px at ' + x + 'px ' + y + 'px)'] },
      { duration: 450, easing: 'cubic-bezier(.16,1,.3,1)', pseudoElement: '::view-transition-new(root)' });
  });
}

// motion.js — count-up（配合 tabular-nums 防抖动）（L1-4）
function countUp(el, to, fmt = v => Math.round(v).toLocaleString(), dur = 600) {
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) { el.textContent = fmt(to); el.dataset.v = to; return; }
  const from = Number(el.dataset.v || 0), t0 = performance.now(); el.dataset.v = to;
  (function frame(now) {
    const p = Math.min(1, (now - t0) / dur), e = p === 1 ? 1 : 1 - Math.pow(2, -10 * p);
    el.textContent = fmt(from + (to - from) * e);
    if (p < 1) requestAnimationFrame(frame);
  })(t0);
}
```
