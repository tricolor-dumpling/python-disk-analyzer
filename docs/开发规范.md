# 开发规范

本文件是 `README.md`「Git 分支规范」与「文档维护规范」的操作手册：**分支怎么用、一次开发怎么走完、
文档什么时候更新**。约束类红线（改代码不能违反什么）在根 `AGENTS.md`，接口与文件清单在 `README.md`，
三者分工不重复。

---

## 1. 分支的作用（一张表看懂）

| 分支 | 作用 | 从哪切 | 合并去向 | 生命周期 |
|---|---|---|---|---|
| `main` | **唯一长期分支**：随时可运行的稳定线，也是唯一对外发版线 | — | — | 永久 |
| `feature/<主题>` | 新功能/新能力（如 `feature/snapshot-calendar`） | `main` | `main` | 合并后删除 |
| `fix/<主题>` | 缺陷修复（含 UI 实测问题、崩溃、文案错误） | `main` | `main` | 合并后删除 |
| `docs/<主题>` | 纯文档变更（README / AGENTS / 来源清单 / docs） | `main` | `main` | 合并后删除 |
| `refactor/<主题>` | 不改行为的结构调整（模块拆分、纯函数提取、依赖理顺） | `main` | `main` | 合并后删除 |
| `release/vX.Y.Z` | 发版冻结：只允许版本号与发布相关改动 | `main` | 打 tag 后回 `main` | 发版后删除 |
| `hotfix/vX.Y.Z` | 已发布版本的紧急修复 | 对应 tag | `main` **和**该发布线 | 回合后删除 |

**硬规则**

1. **一个分支只做一件事**。混装功能的 PR 一律拆开。
2. 分支名**全小写 + 短横线**，禁止中文、空格、个人前缀（不要 `zhangsan/fix`）。
3. `main` 上任何提交都必须能直接 `python app.py` 跑起来 —— 不允许把「半成品」合进 `main`。
4. **已废止** `stage-*` 阶段分支与 `ui*` 版本线分支（历史已于 2026-09-28 压缩为单一根提交）。
   阶段性工作改用 `feature/<主题>`，界面重构改用 `feature/ui-<主题>`。

**准入条件（合并回 `main` 前必须全部满足）**

- 验收命令全绿：`.venv\Scripts\python.exe -m pytest tests -q` + `node --test scripts/dev/`；
- 文档已按第 3 节同步（`tests/test_docs_sync.py` 是这条的机械校验）；
- 提交信息符合第 4 节格式。

## 2. 一次开发的标准流程

```powershell
# 0. 从最新的 main 切出短期分支（分支名 = 主题，一件事）
git switch main
git switch -c feature/trend-window

# 1. 开发（改代码 / 加测试 / 改文档 同步进行，不要留到最后补文档）

# 2. 本地验收（两条都必须跑）
.\.venv\Scripts\python.exe -m pytest tests -q     # 后端全量（含文档同步契约）
node --test scripts/dev/                          # 前端纯 JS 单测
# 涉及界面的改动：浏览器打开 tests/web/smoke.html，标题出 [suite=v2][PASS 23/23] 才算绿

# 3. 按第 3 节同步文档，然后提交
git add -A
git commit            # 提交信息见第 4 节

# 4. 合并回 main 并删除分支
git switch main
git merge --no-ff feature/trend-window
git branch -d feature/trend-window
```

> 改了 `web/templates/index.html` 要**重启** Flask（Jinja 非 debug 模式会缓存编译后的模板）；
> 静态 JS/CSS 不缓存，刷新页面即可。

## 4. 提交信息格式

- 语言：**中文**。
- 首行：**≤ 50 字**，写「做了什么」（动词开头，如 `修复对比页折线点选后多选塌缩`）。
- 正文（可选但推荐）：写「为什么这么改」+「怎么验证的」（跑了哪些命令、结果如何）。
- 一次提交只做一件事；格式化、重命名等无行为变更的改动单独提交。

示例：

```text
修复对比页折线点选后基准多选被塌缩

点选数据点原先直接改 sel.value，而 <select multiple> 的 value 恒为
第一个 selected 项，导致多选被收敛成单选、折线消失。
改为只经 pickBaselineFromTrend() 收口改 state.baseline / dataset.base。

验证：pytest tests -q 全绿；smoke.html 标题 [suite=v2][PASS 23/23]。
```

## 5. 分支上不该出现的东西

- 一次性核查脚本、调试探针、临时 `test_*.py`：**用完即删**，考古走 `git log`
  （可复用的开发工具才放 `scripts/dev/`，且新探针必须 `import _harness.mjs`）。
- 运行时数据（快照 / 导出 / `config.json`）：真实数据在 `%LOCALAPPDATA%\PythonDiskScanner\`，
  **绝不进项目目录、绝不入库**；测试夹具默认写 `%TEMP%`。
- 截图、测试报告、打包产物：写临时目录或系统 Temp。
- 任何令牌 / 凭据：只走管道或环境变量，**禁止写进文件或提交**。
