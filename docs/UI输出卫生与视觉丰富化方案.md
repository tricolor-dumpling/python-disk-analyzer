- 关联文档：`docs/UI设计走查报告.md`（问题总清单）

- 范围：`web/` 前端；部分建议需后端配合（已标注）

## 一、不应该出现的输出（输出卫生）

> 原则：**用户界面只出现用户能理解、且当下需要的信息**。内部标识、原始错误码、实现细节、重复告警都属于"泄漏"。

### A. 原始错误码 / 异常文本直出 ⚠ 最影响专业感

| 现状输出 | 来源 | 问题 |
|---|---|---|
| `扫描失败: Everything查询失败: 2` | `scan.py:181` 直出 `Everything_GetLastError()` | 用户不知道 2 是什么（实际 = `EVERYTHING_ERROR_IPC`，即 IPC 未连接） |
| `Everything 查询失败：'D:\xxx'（错误码 2）` | `dispatcher.py:288`，还带 `!r` 的 Python repr 引号 | 同上，且路径带引号更像调试输出 |

**修复**：建立错误码→文案映射表（前端一份即可）：

```
2 (IPC)  → 「Everything 未连接：请确认 Everything 正在运行并完成索引加载，然后重试」
1 (内存) → 「Everything 内存不足，查询失败」
其他      → 「Everything 查询出错（代码 N），请重启 Everything 后重试」
```

同时**错误只在一处主展示**（错误通知框），状态行收敛为一句话，避免同一错误同时出现在 3–4 处。

### B. 内部标识符 / 文件名直出

- 历史快照列表把 `session_20260822_203757_608541_db6134f9_000001.json` 整串显示——里面有时间戳、**疑似 PID/机器码片段（608541_db6134f9）**、序号，对用户全是噪音；
- 每个盘符行显示 `→ C_20260822_203757_explicit_db6134f9.snap.gz` 原始文件名，且窄容器断词换行（".jso / n"）。

**修复**：主行 = 本地化时间（`2026-08-22 20:38`）+ 手动/自动标签；副行 = `C:\ · D:\ · 共 2 份快照`；完整路径收进「复制路径」次级按钮或 title 悬浮。

### C. 原始 ISO 时间直出

概览盘符卡片 meta 行输出 `2026-08-24T10:21:07`（带 T 的原始 ISO 串），而快照列表又做了 `T→空格`，两处不一致。**修复**：统一 `formatDateTime()`；更友好可显示相对时间「3 分钟前 / 昨天 14:20」，title 里保留精确时间。

### D. 实现细节术语外露

| 现状文案 | 为什么不该出现 | 建议文案 |
|---|---|---|
| 「Everything **IPC** 尚未就绪」 | 用户不懂 IPC | 「Everything 未就绪 · 点击查看解决方法」 |
| 「来自**内存缓存**（无需重新扫描）」 | 实现细节，用户只关心数据新不新 | 「数据已就绪 · 无需重新扫描」 |
| 「1284 个目录 · 58210 个文件 · **59494 条记录** · …」 | `record_count` = 目录+文件之和，与前两个数字重复且无意义 | 删掉「N 条记录」 |
| 页脚「快照、**清单**与配置」/「**本地服务仅监听 127.0.0.1**」 | 「清单」是内部术语（ledger/session json）；端口细节是开发者自证 | 「快照与配置保存在本地数据目录 · 数据不会上传」 |
| 「共 1 个快照**会话**」 | 「会话」抽象 | 「共 1 次保存」 |
| 设置里 readonly 输入框显示 **DLL 完整路径**且截断 | 路径是排障信息，不该占主界面还显示不全 | 摘要文字 + 「复制详细信息」按钮 |

### E. 异常数据无守卫直出

历史截图里出现 **`虚拟磁盘 114688.00 PB`**（Everything 对虚拟磁盘返回的异常值），原样渲染成满格条形。**修复**：单条目 > 1 PB（或 > 总盘容量合理值）时显示「数据异常？」标记并弱化条形，提示索引可能包含虚拟磁盘/网络映射。

### F. 不该缺失的输出（反向问题）

1. **没有 favicon**：`index.html` 未声明图标，标签页是默认白板——项目明明有 `scripts/make_icon.py` 自绘图标，补 `<link rel="icon">` 即可；
2. **使用指引的 4 步骤永远不显示**：`<ol class="steps hidden">` 写了内容但无任何 JS/CSS 让它出现，新用户只能看到一行欢迎语——要么展示，要么删掉；
3. **盘符建议硬编码 `C:\ D:\ E:\ F:\`**：真机上有 G:\Z:\ 或网络盘时缺失；后端已知实际盘符，应动态填充 datalist；
4. **对比基线要手输 `.snap.gz` 完整路径**：应改为下拉选择（选项显示「2026-08-24 10:21 · C:\」友好标签），路径只作内部值。

## 二、让界面更美观、更丰富的设计方案

### 1. 建立视觉系统（美化的地基）

- **深色模式**：CSS 变量体系已就绪，补一套 `prefers-color-scheme: dark` 的变量覆盖 + 设置里「浅色/深色/跟随系统」三选。磁盘工具是典型夜间场景，性价比最高的"高级感"来源。
- **盘符配色**：为每个盘符分配固定色相（C=蓝、D=紫、E=青…），概览条形、扫描进度卡、对比图表全部沿用——同一盘符跨视图颜色一致，是 WizTree/TreeSize 这类工具"看起来专业"的关键。
- **字阶与数字**：定义 12/13/14/16/20/28 六级字阶并明确用途；所有数字列加 `font-variant-numeric: tabular-nums`，大小列右对齐上下行对齐，表格立刻精神很多。
- **文件类型彩色图标**：按扩展名映射色相+图标（视频紫、图片青、压缩橙、文档蓝、镜像红…），排行/表格的扫读效率和大屏观感都会明显提升；仍是内联 SVG，不引外部资源。
- **品牌细节**：logo 渐变已不错；把渐变只保留给「品牌 logo + 主数字（如 127.53 GB）」两处，其余装饰性渐变收敛，避免"到处都在发光"。

### 2. 可视化丰富（磁盘工具的核心美感来源）

- **Treemap 矩形树图（最推荐）**：在「排行 / 表格」旁加第三个视图。SpaceSniffer 式的面积图是磁盘工具最有冲击力的表达：一块矩形=一个目录，面积=占比，点击下钻、与面包屑联动。纯前端可用简版 squarified 算法实现（现有数据结构直接可用）。
- **盘符容量环**：概览卡片顶部加「已用 / 剩余」环形图（如 127.5 GB / 256 GB）。需后端在 `/api/overview` 补 `volume_total_bytes`（Windows `GetDiskFreeSpaceEx` 一行调用）。
- **扩展名构成环**：把现在信息量很低的「目录/文件」二分环升级为 Top-5 扩展名占比环（视频 38% · 镜像 22% · 文档 12%…），点击图例可反筛列表。需后端 browse 结果附扩展名聚合。
- **历史趋势线**：历史快照卡片加一条迷你折线（近 N 次保存的总大小走势），一眼看出"磁盘在涨"。数据就在现有 sessions 里，纯前端可做。
- **对比视图双向条形**：变化排行改为中轴左右发散（涨向左红、跌向右绿），比单色条直观；顶部加「只看新增 / 只看删除 / 全部」筛选 chips。
- **扫描过程卡**：全量扫描时每盘一张进度卡（盘符色点 + 进度条 + 已扫描大小 + 预计剩余时间），替代单一百分比——"丰富感"最直接的来源。

### 3. 微交互与动效（细腻 = 高级）

- **骨架屏替代 spinner**：浏览加载时表格区显示 6–8 行灰条骨架（配合 P0 修复的遮罩样式），观感比转圈快得多；
- **行级动效**：列表行进入时 30ms 级联淡入；大小数字 count-up；条形宽度过渡已有，保持；
- **行悬浮操作**：表格行 hover 时右侧浮现「复制路径 / 在资源管理器中打开 / 在 Everything 中搜索」三个图标按钮——磁盘工具的高频动作，现在一次都没有；
- **Toast 带动作**：「已保存快照」toast 上直接放「撤销」按钮，不用去列表里找；
- **分段控件**：排行/表格/树图改为真分段控件（选中态有滑块），「紧凑列表」改为独立的密度小开关，语义分开；
- **快捷键可发现**：Ctrl+K 跳路径已实现但无任何提示，在搜索框 placeholder 加「Ctrl + K」角标，并做一个快捷键速查小浮层。

### 4. 布局与导航（撑起"应用感"）

- **左侧窄图标导航栏**（≥1200px 显示）：概览 / 浏览 / 扫描 / 快照 / 对比 五个锚点，当前区块高亮——单页五个平铺卡片改成分区结构，页面立刻从"表单"变"应用"；
- **粘性面包屑**：浏览长列表时路径导航吸顶，随时返回上级；
- **空态插画**：三个空态（未扫描/空目录/无快照）用与现有图标同风格的自绘 SVG 小插画 + 一句行动指引（按钮直达「开始全量扫描」），替代纯文字。

### 5. 文案人味（成本最低的"美化"）

- 相对时间：「3 分钟前更新」；
- 大数缩写：「5.8 万个文件」；
- 状态行有温度：「索引是 10 分钟前的，仍然可用」优于「索引有效」。

### 建议落地顺序

| 批次 | 内容 | 成本 |
|---|---|---|
| ① 输出卫生 | 错误码映射、去 session/文件名直出、统一时间、术语替换、favicon | 1–2 天，纯前端 |
| ② 观感速赢 | 深色模式、tabular-nums、文件类型彩色图标、骨架屏、行悬浮操作 | 1–2 天，纯前端 |
| ③ 丰富化 | Treemap 视图、扫描进度卡、对比双向条形、Toast 动作 | 2–3 天，纯前端 |
| ④ 需后端 | 盘符容量环（卷容量）、扩展名聚合环、动态盘符列表 | 各 ~0.5 天后端 + 前端 |
