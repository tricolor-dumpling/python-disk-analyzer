### 2-1. 对比功能一直「正在对比，请稍候」

- **已确认根因（两条叠加）：**
  1. `app.py:604-684 /api/compare`：无全量结果时走 **SDK 直扫分支**（`app.py:635-643`，`scan_via_everything_sdk(Path(raw_root))`）。本机该调用**分钟级**（G8），且 `root` 为盘根（如 `C:\`），条目量 40 万+。请求未完成前前端骨架屏持续。
  2. `compare.js:230` `postJson("/api/compare", …)` **无超时**（api.js 的 postJson 无 AbortController），`compareSnapshots`（202-266）也无「请求时长上限/进度/取消」——后端不动、前端永远等。
  - 次因（截图佐证）：截图基线/目标输入框显示的是**目录路径**而非快照文件路径（datalist 建议是快照路径，输入框可被用户手填成目录）。若 baseline 是目录且存在，`app.py:611-613` 通过存在性校验，`snapshots.load_snapshot`（`app.py:622`）抛异常 → 500 → 前端进入错误态。因此存在「用户手填路径 → 500」与「默认报 SDK 扫描 → 无限 loading」两条用户可感知路径。
- **开发任务：**
  - **B-1（后端）** `/api/compare` SDK 分支改造：①响应前先查 `fullscan.result(root)`（已存在）；②无缓存时**不阻塞直扫**——返回 `202 + {job_id, status:"scanning"}` 异步任务（后端已具备 fullscan 状态机与轮询通道，可复用），前端轮询 `/api/compare/status`；③或至少给 SDK 直扫加**时间上限与取消钩子**（复用 `cancel_event` 机制，`scan.py:313-317` 每 10000 条检查）。④baseline 校验前置：`baseline` 必须命中快照文件命名（`.snap.gz`）且为文件，否则 400「基线不是快照文件」。
  - **B-2（前端）** `compare.js`：①`compareSnapshots` 的 fetch 加 `AbortController` 超时（建议 30s 用户可感知阈值；超时 →「对比超时，可稍后重试/Esc 取消」+ 按钮恢复）；②loading 骨架屏加**取消按钮**与**已用时**；③区分 409/500/超时/machine_mismatch 四种终态文案（现 409/异机已分，500 与超时未分）。
- **验收标准（真实场所）**：无全量结果+Everything 空闲 → 对比在 X 秒内进入「后台扫描中+进度」或明确超时终态，**骨架屏不再无限期**；有全量结果 → 秒级出报告（复用 `fullscan.result`）。
- **开发注意点**：禁止用「删掉 loading 文案」掩盖未收敛（修订清单禁止事项 #3）；`scan.SCAN_LOCK` 被对比直扫占用时，`fullscan.start()` 的后台线程会**排队卡锁**（见 2-7），改造后必须保证对比不再长期持锁。

### 2-13. 第二次扫描停止后仍显示「来自内存缓存」

## 伍、禁止事项与风险（修订清单继承 + 本轮补充）

1. **严禁修改任何业务代码**——本手册为任务授权文档；任何实现必须从新分支开始、每个任务一个变更集。

3. 不要在真实快照目录测试删除/清空/撤销；隔离目录走 W3.5 重定向方案。
4. 不要通过删除 loading 文案掩盖未收敛（2-1/2-9）。
5. 不要通过字段缺失推断缓存来源（2-13/2-20）——后端明确 `source`。
6. 不要为自动扫描删除所有手动恢复入口（2-5）。
7. **禁止硬杀扫描线程**（W2.10 协作取消红线；2-7 看门狗只能置取消事件）。
8. 动画红线 P7（仅 transform/opacity；已知例外 width/background-position/stroke-dashoffset 仅限登记项）；hex 门禁 0（tokens.css 豁免）。
9. 主题/按钮/弹窗 ID 与既有 smoke 断言面保持不变（U1.3/U3.5 纪律）；改 index.html 需重启 Flask（模板缓存）。
10. **行为等价红线**：改 browse/compare/save 等既有接口一律 additive；`switchTheme` 签名与键值语义、`ready/busy` 契约、`SCAN_LOCK` 全局锁对象为本系统三根电线，动前必须评估全链路。
11. 需求未决项（D1–D5）未决策前禁止进入实现；每个实现前先看「先复现清单」对应证据。
