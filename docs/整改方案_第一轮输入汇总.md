## 二、产品经理产出（价值侧决策建议）

**唯一目标句**：让每个新用户在本版本上跑通「就绪 → 可信数字 → 定位大头 → 打开处理 → 存快照 → 次日一键对比」的完整闭环，全程看不到一个错误或看不懂的数字。

**P0（发布门槛，缺一不发版）**
- P0-1 哨兵值过滤：GetResultSize 返回值检查 + 合理上限，全链路生效；
- P0-2 对比合计去重计数：CLI 与 Web 统计卡同口径；
- P0-3 Everything 未就绪引导包：Web 接入 ensure_everything_running 自动拉起 + 错误码中文映射（含 Session 0 专述）+ 首屏引导态 + 徽章一键启动；
- P0-4 行动闭环最小集：「打开所在文件夹」+「复制路径」，顺带修文件行重复扫描 bug。

**P1**：一键对比（快照列表逐条按钮 + 仅看叶子变化开关 + 指引第4步改为次日对比）；前端毛刺批（筛选空态/撤销禁用/非目录校验/焦点/R键）；后端稳定包最小补丁（SDK 统一持锁、陈旧锁 PID 检测、日配额接线、TUI 收敛、CLI 边角）。
**P2 顺延下轮**：定时快照、Web 导出、设置扩展、MFT 引擎、vitest 全套、dispatcher 启用、更名。
**投入比例**：工程正确性 : 产品价值 ≈ 4:6。

**Non-goals**：删除/移动文件；MFT 备用引擎；定时快照/自启/托盘；Web 导出与设置扩展；dispatcher 重构与测试框架全面建设；空目录统计口径变更（改文档不改行为）；API/快照格式变更。

**验收标准（P0）**：
1. 注入哨兵值夹具+真实脏索引机器上任一输出无超限条目；C 盘概览总占用 vs 资源管理器偏差 ≤5%；单测入回归；
2. 夹具 7050B→6050B 场景合计 = −1000B 且等于根行 delta，Web 三卡一致；
3. 两种未就绪环境冷启动首屏 0 裸错误码；≤2 次点击触发启动后 ≤15 秒徽章变绿；错误映射全覆盖；须验证「Everything 管理员运行而本工具非管理员」场景文案；
4. 任意行 ≤2 次点击完成打开定位或复制路径（剪贴板==绝对路径）；文件行点击产生 0 个额外 /api/browse。

**指标集**：环境就绪率 → 首次全量扫描完成率 → 行动闭环率（新）→ 快照保存率 → 7 日对比回访率；红线「天文数字输出率=0」。落地：本地 JSONL 事件日志（默认记可关不出网）。
**更名**：本轮不做；仅铺垫——用户可见层不再新增 Python 字样 + 页脚版本号。
