记录格式（一条一段，保持简短、可追溯）：

```
## YYYY-MM-DD · <分支名或主题>
- 变更：做了什么（面向使用者/开发者可感知的结果）
- 文件：新增/删除/改名的文件（同步 README 文件总表）
- 验证：跑了什么命令、结果如何
- 文档：同步更新了哪些文档
- 遗留：未完成项 / 已知限制（没有就写「无」）
```
