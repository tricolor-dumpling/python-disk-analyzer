# 变更日志（CHANGELOG）

本文件按**时间倒序**记录每次开发迭代的产出，配合 `README.md`「文档维护规范」使用：
每次开发完成后，除了更新 `README.md` 的文件总表与 `AGENTS.md` 的红线，**还要在下面追加一条记录**。

记录格式（一条一段，保持简短、可追溯）：

```
## YYYY-MM-DD · <分支名或主题>
- 变更：做了什么（面向使用者/开发者可感知的结果）
- 文件：新增/删除/改名的文件（同步 README 文件总表）
- 验证：跑了什么命令、结果如何
- 文档：同步更新了哪些文档
- 遗留：未完成项 / 已知限制（没有就写「无」）
```
