# 临时工作区

本目录**整个不入库**（`.gitignore` 已忽略 `/tmp/`），是开发过程中的**可随时整体删除**的落点。
它存在的唯一目的：让临时产物有个固定去处，不再散落在仓库根目录。

```powershell
Remove-Item -Recurse -Force tmp\*      # 想清就清，不必先看里面有什么
```

## 可以放什么

| 类型 | 示例 |
|---|---|
| 一次性排查脚本 | 临时 AST 提取、批量改名脚本、数据核对脚本 |
| 抓取到的证据 | 测试输出、日志片段、性能计时结果 |
| 界面截图 / 录像 | 排查 UI 问题的 `browser_screenshot` 产物、动效帧序列 |
| 草稿 | 还没定稿的文档、方案、表格 |
| 解压/试装现场 | 发布包试解压目录、依赖试装沙箱 |

## 绝对不能放什么

- **真实运行数据**（业务数据，不是临时文件）：`%LOCALAPPDATA%\PythonDiskScanner\` 下的快照 / 导出 /
  session 清单 / `config.json` 一律不进仓库，见根 `AGENTS.md` 第 6 节。
- **任何令牌、凭据、密钥**：临时目录同样适用「只走管道或环境变量」。
- **需要长期保留的东西**：本目录随时可能被整体删除，要留就放 `docs/` 或 `scripts/dev/`。

## 与其它落点的分工

| 产物 | 落点 | 是否入库 |
|---|---|---|
| 一次性脚本、日志、截图、草稿 | `tmp/`（本目录） | 否，随时删 |
| **可复用**开发工具、前端单测 | `scripts/dev/` | 是（≤10 个文件，见该目录 README） |
| 测试夹具 | `%TEMP%\pds_fixture_snapshots_<ts>` | 否（**不得**指向真实数据目录） |
| 破坏性验收的隔离数据根 | `D:\deepseek\dsa-isolated\<时间戳>` | 否（用 `-Cleanup` 清理） |
| 需要长期保留的文档 | `docs/`、`README.md`、`AGENTS.md` | 是 |

> 纪律：**临时脚本用完即删**（考古走 `git log`，不要建 `archive/`）；可复用的才升级进 `scripts/dev/`。
