# web/static/assets/ — 界面素材来源与授权清单

本目录存放**需要登记来源的第三方素材**（图片、字体、音效等）。Web UI 的图标全部为内联 SVG 代码
（`web/static/js/app/icons.js` 的 `ICONS` 表 + `web/templates/index.html` 内联的 data-URI 站点图标），
字形一律使用系统字体栈，因此**当前目录不含任何第三方素材文件**，本清单为空表是预期状态。

## 登记规则（新增素材必须遵守）

1. **只接受可自由再分发的素材**：CC0 / 公有领域（Public Domain）/ 自绘自产。
   不接受来源不明、需署名但未署名、或禁止商用的素材。
2. **新增素材必须在本表登记后才可提交**（未登记素材不得入库）：
   - 文件名、放入的子目录、用途（在哪个界面/组件使用）；
   - 原始来源 URL 与作者；
   - 许可证名称与获取日期。
3. **优先内联**：能用 SVG 路径或 data-URI 表达的简单图形，直接写在 `icons.js` / 模板里，
   不要新增二进制文件——既省一次请求，也免去授权登记负担。
4. **禁止外链 CDN**：本项目是纯本地工具（Flask 只绑 `127.0.0.1`），界面不得引用任何外部网络资源。
