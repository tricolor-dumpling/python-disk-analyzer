# UI 素材来源清单

> 本目录（`web/static/assets/`）用于记录界面素材的来源与授权情况。
> 约定：**只使用免版权（CC0 / 公有领域 / 自绘原创）素材**；优先内联 SVG。

## 当前状态（2026-08-22，Phase 3）

| 素材类型 | 位置 | 来源 | 授权 |
|---|---|---|---|
| 全部界面图标（顶栏 Logo、目录/文件、盘符、设置、搜索、刷新、撤销、对比、清空、加载 spinner、提示图标等） | `web/templates/index.html` 与 `web/static/js/app/icons.js` 中的**内联 SVG**（U4.3 更新：图标现已集中到 `js/app/icons.js`，壳级/模板内联图标仍在 index.html） | 本项目作者手工绘制（原创） | 原创，随项目代码一并使用，无第三方版权 |
| 字体 | 无字体文件 | 仅使用操作系统自带字体（Segoe UI / Microsoft YaHei / PingFang SC 回退栈） | 系统字体，不随项目分发 |
| 配色与样式 | `web/static/css/style.css` | 本项目自定设计规范 | 原创 |

## 决策说明

按开发方案 3.3「优先内联 SVG；**需**位图/插画时再下载素材」：

- 本阶段界面所需图标均能用简单几何线条表达，**全部自绘为内联 SVG**，
  无需下载任何位图或插画素材；
- 因此本目录当前**没有外部下载的素材文件**，也不存在版权风险；
- 未使用 modsearch 下载素材：不是拒绝使用，而是「无位图需求」。

## 将来若新增位图 / 插画

必须在本清单追加一行，至少记录：

1. 文件名与用途；
2. 下载来源 URL；
3. 授权类型（仅接受 CC0、公有领域或明确「可商用免署名」授权）；
4. 下载日期与素材作者。

> 凡未在本清单登记的图片素材，一律不得提交进仓库。
