Python 磁盘扫描

空间分析工作台

👋 欢迎使用 Python 磁盘扫描

先扫描一次，建立空间索引。

  1. 1
    检查环境

    确认右上角状态为「Everything 已就绪」。若未就绪，请先打开 Everything 并等待索引加载完成。

  2. 2
    全量扫描

    点击「开始全量扫描」，程序在后台依次扫描 C、D 等所有本地盘，进度条实时显示。

  3. 3
    保存快照

    扫描完成会提示「是否保存本次快照」，保存后生成 C、D 各一份快照与清单；也可在设置中开启自动保存。

  4. 4
    对比与清空

    在「历史对比」中与基线快照对比找出变化；设置里可一键清空数据目录（需输入确认文字）。
